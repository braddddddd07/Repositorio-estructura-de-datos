ESTRUCTURA DE DATOS: PILA (STACK)

Fundamentos LIFO, Notación Posfija/Prefija y Recursividad de Hanoi

CONCEPTO LIFO

¿Qué es una Pila (Stack)?

Una Pila es una estructura de datos lineal que opera bajo el principio LIFO (Last In, First Out): el último elemento en ingresar es el primero en salir. Sus operaciones fundamentales son:

  • push(item): Apila un elemento en el tope.
  • pop(): Desapila y retorna el elemento en el tope.
  • peek() / top(): Consulta el elemento del tope sin removerlo.
  • is_empty(): Verifica si la pila se encuentra vacía.

Notación Posfija y Prefija

Las notaciones polacas eliminan la necesidad de paréntesis al evaluar expresiones algebraicas:

POSFIJA (RPN - Reverse Polish Notation)

Los operadores van después de los operandos. Ejemplo: 5 3 + 2 * equivale a (5 + 3) * 2 = 16.

PREFIJA (Notación Polaca Directa)

Los operadores van antes de los operandos. Ejemplo: * + 5 3 2 procesado de derecha a izquierda equivale a 16.

Torres de Hanoi con Pilas

El acertijo clásico de las Torres de Hanoi modela 3 postes como 3 objetos de la clase Pila. Sus reglas fundamentales son:

  1. Solo se puede mover un disco a la vez (un pop() de la pila origen y un push() en la destino).
  2. Un disco mayor jamás puede colocarse sobre un disco menor.
  3. El número mínimo de movimientos para $n$ discos es $2^n - 1$.

class Pila:
    """Implementación de una Pila (LIFO) usando Listas en Python."""
    def __init__(self, nombre="Pila"):
        self.items = []
        self.nombre = nombre

    def push(self, item):
        """Apila un nuevo elemento."""
        self.items.append(item)

    def pop(self):
        """Desapila y retorna el elemento superior."""
        if not self.is_empty():
            return self.items.pop()
        raise IndexError("pop() realizado en una Pila vacía")

    def peek(self):
        """Retorna el elemento superior sin desapilarlo."""
        if not self.is_empty():
            return self.items[-1]
        return None

    def is_empty(self):
        """Verifica si la pila está vacía."""
        return len(self.items) == 0

    def size(self):
        """Retorna la cantidad de elementos."""
        return len(self.items)

    def __str__(self):
        return f"{self.nombre}: {self.items}"

def evaluar_posfija(expresion):
    """Evalúa expresiones en notación Posfija (RPN). Ej: '5 3 + 2 *'"""
    pila = Pila("EvaluadorPosfijo")
    tokens = expresion.split()

    for token in tokens:
        if token.isdigit() or (token[0] == '-' and token[1:].isdigit()):
            pila.push(float(token))
        else:
            b = pila.pop()
            a = pila.pop()
            if token == '+': pila.push(a + b)
            elif token == '-': pila.push(a - b)
            elif token == '*': pila.push(a * b)
            elif token == '/': pila.push(a / b)
            elif token == '^': pila.push(a ** b)

    return pila.pop()


def evaluar_prefija(expresion):
    """Evalúa expresiones en notación Prefija. Ej: '* + 5 3 2'"""
    pila = Pila("EvaluadorPrefijo")
    tokens = expresion.split()

    # Se procesa de derecha a izquierda
    for token in reversed(tokens):
        if token.isdigit() or (token[0] == '-' and token[1:].isdigit()):
            pila.push(float(token))
        else:
            a = pila.pop()
            b = pila.pop()
            if token == '+': pila.push(a + b)
            elif token == '-': pila.push(a - b)
            elif token == '*': pila.push(a * b)
            elif token == '/': pila.push(a / b)
            elif token == '^': pila.push(a ** b)

    return pila.pop()

def resolver_hanoi(n, origen, destino, auxiliar):
    """Resuelve Torres de Hanoi utilizando 3 Pilas explícitas."""
    if n == 1:
        disco = origen.pop()
        destino.push(disco)
        print(f"Mover disco {disco} de {origen.nombre} a {destino.nombre}")
    else:
        resolver_hanoi(n - 1, origen, auxiliar, destino)
        disco = origen.pop()
        destino.push(disco)
        print(f"Mover disco {disco} de {origen.nombre} a {destino.nombre}")
        resolver_hanoi(n - 1, auxiliar, destino, origen)
